Node Browser is a single Node.js web service for Render. Set ACCESS_PASSWORD (12+ characters) and SESSION_SECRET (32+ random characters) in the Render environment. Use npm install to build and npm start to run. Open the service over HTTPS, sign in, and enter a web address. The UI and WebSocket endpoint are served by the same service. The Wisp layer restricts destination ports to 80 and 443, disables UDP and direct IP connections, and blocks private and loopback destination addresses. Keep the password private. Upstream components: Ultraviolet, Epoxy Transport, Bare-Mux, and Wisp JS.
